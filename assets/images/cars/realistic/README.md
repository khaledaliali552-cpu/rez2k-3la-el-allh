# صور المركبات

الصور هنا بتتستخدم فى مكانين:
1. **كروت الجراج والإعداد والورشة**: بتتسجل فى `js/car-images.js` (نوع المركبة + اللون).
2. **زحمة الطريق**: بتتسجل فى `js/sprites.js`. صور "من ورا" للعربيات اللى قدامك، وصور "من قدام" للعربيات العكسية.

صيغة الصور: WebP أو PNG بخلفية شفافة، مقصوصة على حدود العربية.
اللى اتشال منه الخلفية من صور مرسوم عليها مربعات الشفافية (الجيب المربع، اللادا، كورولا، إم جى، بيجو) جودته أقل لو كان من Screenshot؛ الأفضل ترفع الأصل.
