# 🚖 أجرة الكورنيش (Corniche Cab)

لعبة سواقة تاكسى 3D بتتلعب من المتصفح (كمبيوتر وموبايل)، من غير تحميل أو تسجيل.
أنت سواق على تاكسى بتاع "المعلم"، بتوصّل ركاب على كورنيش طويل، بتجمع فلوس، وبعدين تشترى عربيتك.

> لعبة مستقلة: الكود والتصميم والأسماء كلها أصلية، ومفيهاش أى أصول من لعبة تانية.

## اللعب

| الفكرة | التفاصيل |
|---|---|
| **البداية** | بتشتغل على تاكسى المعلم، وبتدفع له **حساب 350 جنيه** فى آخر كل وردية. |
| **الطرق (5)** | **طريق البشاوات** 150 ج/فرد (غالية) · **أبو قير** 70 · **المحمودية** 60 · **السريع** 50 · **الصحراوى** 40 (رخيصة عشان الغلابة). كل طريق ليه بيئة ومحطات وزحمة مختلفة. |
| **الركاب** | فرد أو مجموعة (لحد سعة العربية). الأجرة = سعر الطريق × عدد الأفراد. |
| **المحطات** | الوجهة دايما محطة على الطريق (قسم باب شرق، شارع محسن، العامرية…) ولافتة خضرا قبلها. |
| **الإفيهات** | الركاب بيتكلموا وهما راكبين، وفى جمل مخصوصة لمحطات معينة (قسم باب شرق، شوارع المحمودية). |
| **الرادارات** | عدّى الرادار بسرعة قانونية وإلا الغرامة 200 جنيه. |
| **الجراج** | 8 عربيات مصرى الشكل، وألوان بتتشترى بالفلوس لكل عربية. |
| **الدعوات** | كود + رابط واتساب. اللى يدخل منه بياخد 300 جنيه. |
| **الراديو** | أغانى mp3 بتضيفها انت + إيقاع شعبى متولّد بالكود. |

### التحكم

- **كيبورد:** `↑`/`W` بنزين · `↓`/`S`/مسافة فرامل · `←` `→` أو `A` `D` دريكسيون · `H` كلاكس · `Esc` إيقاف
- **موبايل:** أزرار على الشاشة (دريكسيون، بنزين، فرامل، كلاكس). فى الإعدادات تقدر تشغّل "بنزين أوتوماتيك".

التقدم بيتحفظ تلقائى فى المتصفح (`localStorage`).

## تشغيلها على جهازك

مفيش build ولا تثبيت. أى سيرفر ملفات ثابتة يكفى (لازم سيرفر، مش فتح الملف مباشرة، عشان ES modules):

```bash
python3 -m http.server 8000
# وافتح http://localhost:8000
```

## النشر على GitHub Pages

1. اعمل ريبو جديد على GitHub وارفع المشروع:
   ```bash
   git remote add origin https://github.com/<اسمك>/corniche-cab.git
   git branch -M main
   git push -u origin main
   ```
2. من **Settings → Pages** اختار **Source: GitHub Actions**.
3. أول push على `main` هيشغّل `.github/workflows/pages.yml` وينشر اللعبة على:
   `https://<اسمك>.github.io/corniche-cab/`

## هيكل المشروع

```
index.html          الصفحة والشاشات (عربى RTL)
css/style.css       التصميم
js/main.js          ربط كل حاجة + الوردية + المهام + الحفظ
js/world.js         الكورنيش: الطريق، البحر، العمارات، النخل، الرادارات
js/car.js           فيزياء عربية اللاعب
js/traffic.js       زحمة الطريق (ذكاء العربيات) والعربيات العكسية
js/rides.js         الركاب: الركوب، التوصيل، حساب الأجرة والبقشيش
js/vehicles.js      مجسمات العربيات والناس (مكعبات بسيطة)
js/data.js          العربيات، الركاب، المهام، الإنجازات (هنا بتعدّل الأرقام)
js/ui.js            القوايم والـ HUD
js/input.js         كيبورد + لمس
js/sfx.js           أصوات WebAudio (من غير ملفات)
js/save.js          الحفظ
vendor/             نسخة Three.js (رخصة MIT)
```

## تعديلات سهلة

- **أرقام الاقتصاد والتوازن:** `js/data.js` (أسعار العربيات، حساب المعلم `fee`، مدة الوردية `SHIFT_SECONDS`، غرامة الرادار).
- **ركاب وأماكن جديدة:** أضف عناصر فى `PASSENGERS` و`PLACES`.
- **مكان تانى غير الكورنيش:** شكل الطريق والبيئة فى `js/world.js` (`_buildChunk`) والألوان فى `THEMES`.
- **مهام وإنجازات:** `QUEST_POOL` و`ACHIEVEMENTS`.

## الرخص

Three.js (MIT) فى `vendor/`. باقى الكود تقدر تحط له الرخصة اللى تناسبك قبل النشر.


## إضافة أغانى mp3 للراديو

1. حط ملفات الـ mp3 فى فولدر `audio/`.
2. افتح `audio/playlist.json` وسجّلها:
   ```json
   [
     { "title": "اسم الاغنية", "file": "song1.mp3" },
     { "title": "مهرجان", "file": "mahragan1.mp3" }
   ]
   ```
3. ارفع التغييرات (Commit + Push) وهتظهر فى قايمة الراديو.

**مهم قانونيا:** استخدم أغانى عندك حقوقها أو مرخصة أو من إنتاجك. نشر أغانى محمية على موقع عام ممكن يسبب مطالبات حقوق نشر.

## تعديل الطرق والمحطات

كل شىء فى `js/roads.js`: الأسعار، أسماء المحطات، الجمل المخصوصة لكل محطة (`lines`)، مزيج العربيات والزحمة. والإفيهات العامة فى `js/dialog.js`.

## الحسابات (Firebase)

- الإعدادات فى `js/firebase-config.js`، والكود فى `js/cloud.js`.
- **قواعد الأمان:** انسخ محتوى `firestore.rules` والصقه فى Firebase Console ← Firestore Database ← Rules ← Publish.
- لازم تفعّل Authentication ← Email/Password، وتضيف دومين `khaledaliali552-cpu.github.io` فى Authorized domains.
- بيتخزن: الإيميل والاسم والتقدم وكود الدعوة. صفحة `privacy.html` فيها سياسة الخصوصية.
- التقدم بيتحفظ من جهاز اللاعب (مش سيرفر موثوق)، فالغش ممكن تقنيا. مناسب للعبة بين أصحاب.
